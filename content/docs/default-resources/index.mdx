---
title: Default resources
description: The resources every server ships with, and how to configure them.
---

Every server package comes with these resources in its `resources` folder. Change their `config.lua` and run `restart <name>` in the Live Console, or replace them with your own.

<Cards>
  <Card title="worldmanager" href="/docs/default-resources/worldmanager" description="The world clock, day length and weather." />
  <Card title="spawnmanager" href="/docs/default-resources/spawnmanager" description="Where players join, what they wear, and respawning after death." />
  <Card title="chat" href="/docs/default-resources/chat" description="The chat box, commands with suggestions, and private messages." />
  <Card title="appearance" href="/docs/default-resources/appearance" description="The character screen on first join and /appearance, saved per account." />
</Cards>

<Callout type="info" title="Updates">
  A panel update replaces the server programs only and never touches the `resources` folder, so your edits are safe. To get a newer version of a default resource, copy it from the latest server package.
</Callout>
