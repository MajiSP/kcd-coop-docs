KCD Co-op is a multiplayer platform for **Kingdom Come: Deliverance II**. You run a server, players join it from the KCD Co-op launcher, and everything that happens in the world is decided by **resources**: folders of Lua scripts and web pages that you write or install, in the same spirit as FiveM.

## How it fits together

- **The panel** (`KCDCoopServer.exe`) is a web admin panel in the style of txAdmin. It starts and watches the game server, shows the console, players and bans, and holds your settings.
- **The game server** runs every resource's **server scripts** (Lua 5.4) and relays players to each other.
- **Players' games** run each resource's **client scripts** inside Kingdom Come's own Lua, and show its **UI page** in an embedded browser on top of the game.

<Callout type="info" title="Versions">
  The server and the players must run the same KCD Co-op build. The launcher downloads the right one for each server automatically, and the panel can update the server for you.
</Callout>
